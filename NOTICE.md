# Public Showcase Mirror

This repository is a sanitized public mirror of a private production codebase,
generated by an automated pipeline (showcase-sync).

- Secrets, environment files, business data, and internal operational documents
  are excluded or redacted at generation time.
- History is flattened: each commit is a snapshot sync from the private repo,
  so private history (and anything it ever contained) is never published.
