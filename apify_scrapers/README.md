# Apify + Crawlee Web Scraping Setup

This directory contains two web scrapers built with Apify and Crawlee:
- **static-scraper**: Fast scraper for static HTML sites (uses CheerioCrawler)
- **dynamic-scraper**: Full browser scraper for JavaScript-heavy sites (uses PlaywrightCrawler)

## Architecture (3-Layer System)

Following the project's 3-layer architecture:

**Layer 1: Directive** → `directives/scrape_website.md`
- Instructions for what to scrape, when to use each scraper, and edge cases

**Layer 2: Orchestration** → `execution/run_apify_scraper.py`
- Python script that calls the scrapers with proper config
- Handles input preparation, execution, and result processing

**Layer 3: Execution** → This directory (`apify_scrapers/`)
- Deterministic Node.js scrapers that do the actual web scraping
- Reliable, testable, and focused on one job

### 3. Use in Your Workflows
```python
from execution.run_apify_scraper import ApifyScraper

# For static sites (fast)
scraper = ApifyScraper(scraper_type="static")
result = scraper.scrape(
    start_urls=["https://example.com"],
    selectors={
        "title": "h1",
        "description": "p.intro",
        "links": "a@href"  # @ extracts attributes
    },
    max_pages=10,
    follow_links=False
)

# For dynamic sites (slower, but handles JS)
scraper = ApifyScraper(scraper_type="dynamic")
result = scraper.scrape(
    start_urls=["https://spa-website.com"],
    selectors={"data": ".dynamic-content"},
    max_pages=5,
    waitForSelector=".dynamic-content",  # Wait for element
    waitTime=3000  # Or wait for X milliseconds
)
```

## How It Works

### Static Scraper (Cheerio)
1. Fetches HTML with HTTP requests
2. Parses HTML with Cheerio (jQuery-like selectors)
3. Extracts data based on your selectors
4. Very fast, low resource usage
5. **Best for**: Blogs, news sites, documentation, static e-commerce

### Dynamic Scraper (Playwright)
1. Launches a headless Chromium browser
2. Loads pages like a real browser (executes JavaScript)
3. Waits for content to render
4. Extracts data from the fully-rendered DOM
5. **Best for**: SPAs, sites with infinite scroll, AJAX-heavy apps

## Selector Syntax

```javascript
// Text content
"h1"              → First <h1> text
"p"               → Array of all <p> texts
".class"          → Elements by class
"#id"             → Element by ID

// Attributes (use @)
"a@href"          → Array of all link URLs
"img@src"         → Array of all image sources
"button@data-id"  → Custom data attributes
```

## Configuration Options

```python
scraper.scrape(
    start_urls=[...],          # Required: URLs to start from
    selectors={...},           # Required: What data to extract
    max_pages=100,             # Max pages to crawl
    follow_links=False,        # Follow links on pages?
    output_path=Path(...),     # Where to save (default: .tmp/scraped_data/)

    # Dynamic scraper only:
    waitForSelector=".content", # Wait for specific element
    waitTime=2000,              # Wait time in milliseconds
    maxConcurrency=3            # Browser instances
)
```

## Troubleshooting

### "Project not found" Error
Run: `python execution/setup_apify.py`

### Static Scraper Returns Empty Data
- The site likely uses JavaScript to load content
- Switch to `scraper_type="dynamic"`

### Dynamic Scraper Timeout
- Increase `waitTime` parameter
- Check if `waitForSelector` is correct
- Site might have bot detection (see directive)

### Rate Limiting / 429 Errors
- Reduce `maxConcurrency` (default: 5 static, 3 dynamic)
- Add delays between requests (update main.js)
- Consider using proxies

### Memory Issues
- Reduce `maxConcurrency` to 1-2
- Lower `max_pages`
- Process results in batches

### Running Directly (Without Python)
```bash
# Create input.json manually
cd static-scraper
cat > input.json << EOF
{
  "startUrls": [{"url": "https://example.com"}],
  "maxRequestsPerCrawl": 10,
  "selectors": {
    "title": "h1",
    "content": "p"
  }
}
EOF

# Run scraper
npx apify run

# Check results
cat apify_storage/datasets/default/*.json
```

### Deploying to Apify Platform
1. Create account at https://apify.com
2. Install CLI: `npm install -g apify-cli`
3. Login: `apify login`
4. Push scraper: `cd static-scraper && apify push`
5. Run on cloud: `apify call [actor-id]`

## Performance Benchmarks

| Scraper Type | Speed        | Resource Usage | Use Case                |
|--------------|--------------|----------------|-------------------------|
| Static       | 10-50 pg/sec | Very Low       | Blogs, docs, news       |
| Dynamic      | 1-5 pg/sec   | High           | SPAs, JS-heavy sites    |

## Cost Considerations

- **Static scraping**: Near zero cost (just bandwidth)
- **Dynamic scraping**: Higher CPU/memory usage
- **Apify Cloud**: Pay per compute unit if deployed
- **Recommendation**: Always try static first
